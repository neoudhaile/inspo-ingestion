# Keerthi's Website
> Hi, I'm Keerthi — Visual Designer  ·  [kiira.in](https://kiira.in/)

![kiira.in](../../screenshots/kiirain.png)

**Vertical:** #vertical/portfolio  ·  **Vibe:** #vibe/organic-warm #vibe/retro  ·  **Topics:** #topic/design  ·  **Mode:** #mode/light

## What it is
The portfolio of Keerthi (@kiiradesign), described in its meta as 'a visual designer based in India.' Built on Framer.

## What it shows
A hero — 'Hi, I'm Keerthi / Visual Designer' — wreathed in cut-out floral/lily-pad collage illustrations, then a two-column project grid: 'Build Story' (brand identity & graphic design for a global hackathon), 'brushless' (product design and brand identity for an EF-backed startup), a cover-art piece for composer Somnium Monkey's single 'The Prelude to Everything', and 'Visual Poetry' (turning poems into generative art). It closes with an 'Available for full-time roles and creative collaborations' line and a 'Get in Touch' contact card.

## How it works
A Framer-hosted vertical-scroll page (~3,540px) with a top WORK / PLAY / ABOUT nav; project thumbnails sit in a two-up grid and one embedded iframe carries an interactive piece.

## How it's designed
Warm cream canvas (#f5f1eb) with dark-brown ink (#282522), set almost entirely in Courier Prime monospace — the Framer font stack makes it the primary family — with Petrona serif and Satoshi as supporting faces. The token palette also stashes green (#13301b / #396e68), blue (#419fd9) and deep red (#900000) accents. The naturalistic floral collage against the typewriter type gives it a warm, handmade-zine feel.
