## How it's designed
Bold, high-contrast editorial design: a lilac page (rgb(238,219,240) / ~#eedbf0) with crimson-red headings and links (rgb(186,11,33) / #ba0b21) and near-black body text. The hero headline is a huge 100px 'Open Sauce One Taste' display cut, while body copy falls back to system SF Pro (-apple-system) at 14px — no body webfont payload. The CSS carries a fuller dark zinc-based token system (--zinc-950 #0e0e0e, --accent → --pink-400 #fb5ab2), but this page renders in the light lilac/red theme. Built lightweight (LightningCSS) with visitors.now for analytics.
