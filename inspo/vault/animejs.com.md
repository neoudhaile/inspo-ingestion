## What it is
Home page of Anime.js, a lightweight JavaScript animation library, now billed as an 'all-in-one animation engine'.

## What it shows
A feature tour: intuitive API, enhanced transforms, Scroll Observer, advanced staggering, SVG toolset, springs and draggable, and responsive animations. It ends with sponsors and a 'Start animating' call to action.

## How it works
A very long page (about 21,142px) with 6 canvases and 110 inline SVGs, used for live demos of the library running on itself. Scripts come only from the site plus Google Tag Manager and Carbon Ads. No framework global was detected, so it is likely hand-built with the library itself.

## How it's designed
Warm charcoal (--hex-black #252423, body rgb(37,36,35)) with warm off-white text (#f6f4f2) and a hot red accent (#ff4b4b), which is the SPONSOR button colour. The token system is a graded scale: --hex-white-1..8 and --hex-red-1..8. Type is the DIN family for UI plus a monospace for labels. The h1 is a 12px label-style element, so the big 'All-in-one animation engine' copy is an h2.
