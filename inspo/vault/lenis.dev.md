# Lenis – Smooth Scroll
> The smooth scroll library, by darkroom.engineering  ·  [lenis.dev](https://lenis.dev/)

![lenis.dev](../../screenshots/lenisdev.png)

**Vertical:** #vertical/startup-product  ·  **Vibe:** #vibe/experimental #vibe/technical  ·  **Topics:** #topic/engineering #topic/design  ·  **Mode:** #mode/dark

## What it is
The site for Lenis, a lightweight open-source smooth-scroll library for JavaScript, React and Vue from darkroom.engineering, supporting horizontal and infinite scrolling, snapping and touch.

## What it shows
A tall (37462px) black scroll narrative: 'SMOOTH SCROLL', 'WHY SMOOTH SCROLL?', 'SO WE BUILT WEB SCROLLING', 'ENTER LENIS', 'AS IT SHOULD BE', backed by 16 video elements and a canvas. The h1 is a small 14px label: 'THE SMOOTH SCROLL LIBRARY BY DARKROOM.ENGINEERING'.

## How it works
Nav: Showcase, Templates, Submit, Documentation (GitHub README) and Sponsor. The page runs Lenis itself (a .lenis class/global is present), so the scroll feel is the demo.

## How it's designed
Pure black ground (rgb(0,0,0)) with off-white text (rgb(239,239,239)); Anton for giant condensed display, Panchang 700 for accents, Roboto 400/900 for small copy. Layout is a 6-column grid on mobile driven by vw-scaled custom properties (--gap, --safe, --spacer-*, computed from a 375px design width) plus a full set of named easing curves (--ease-in-quad etc.).
