# Neha Sharma - Software Engineer | Tech Blog on React, System Design & AI
> Software engineer sharing insights on React, Next.js, System Design, AI, and Accessibility — technical blogs, tutorials, and book recommendations.  ·  [nehasharma.dev](https://nehasharma.dev)

![nehasharma.dev](../../../screenshots/nehasharmadev.png)

**What it is** — The personal site and tech blog of Neha Sharma, a software engineer. It's a content hub, not a portfolio brag-sheet — the whole page is built around her writing on React, Next.js, System Design, AI/MLOps, AWS and Accessibility, plus a running 'Weekly System Design Sessions' series.

**What it shows** — A landing feed framed by a hand-drawn 'neha sharma' script wordmark up top. Three pinned-post cards sit in colored panels (an 'AWS Architecture Bytes' collection, an 'AI vs ML vs MLOps: A Developer's Roadmap', and 'Claude Certified Architect: My Learning Notes'), followed by a chronological post list with tag chips and dates, a 'Categories' tag-cloud sidebar, and a 'System Design' section of three more cards (Weekly Sessions, Advanced Topics, a Roadmap for Beginners). It closes on a playful 'made with ❤️' footer with a little avatar.

**How it works** — A straightforward Next.js blog: the pinned cards and list rows link out to individual posts, the category chips act as filters, and a 'Read more' button extends the feed. Hovered post rows surface their summary text. Navigation is a single scrolling column with a top-right menu toggle.

**How it's designed** — Warm and homemade rather than corporate. A cream paper ground (rgb(235,234,221)) carries black body copy set in the plain system sans stack (-apple-system / Segoe / Roboto), so the personality comes entirely from the cursive hand-drawn wordmark and the candy-colored card panels (coral/orange and soft pinks per the --pink-400 #ffd2f7 / --pink-200 #ffe0e0 tokens) with rounded corners and soft drop shadows. Links use the default Next.js blue (#0070f3). Built on Next.js + Tailwind, with a Mansalva script webfont declared (CSS var --Mansalva) for the wordmark though document.fonts reported nothing loaded at probe time.

**Palette** — Cream paper ground (rgb(235,234,221)) with black text; pastel card panels — soft pink (--pink-400 #ffd2f7, --pink-200 #ffe0e0) plus coral/orange accents; Next.js blue links (#0070f3).
**Fonts** — Body/headings ride the system sans stack (-apple-system, Segoe UI, Roboto); a Mansalva script webfont is declared for the hand-drawn wordmark (no webfont reported loaded at probe time).
