# Real-Time B2B Data Broker via API or Data Feed | Crustdata
> People and Company Search for AI  ·  [crustdata.com](https://crustdata.com/)

![crustdata.com](../../../screenshots/crustdatacom.png)

**What it is** — The marketing site for Crustdata, a B2B data provider that sells real-time company and people datasets through APIs and live signal feeds — pitched, per its own H1, as 'People and Company Search for AI' and elsewhere as a 'Google For AI Agents'.

**What it shows** — A long product landing page: a particle-globe hero, then sections for 'The Only Platform Providing Truly Real-Time Data', 'Power Your AI Intelligence Layer', 'Build AI Agents For' (GTM, Sales, Competitor Tracking, Investment Screening), bulk profile delivery refreshed monthly, 'Use Data In Creative Ways', and 'Never Again Miss An Opportunity To Act' — interleaved with code snippets, dashboard mockups, and a customer-logo strip.

**How it works** — A standard scroll-driven Framer marketing page (~10.4k px tall) with reveal-on-scroll sections, embedded code blocks demonstrating the API, an Intercom chat widget, and HubSpot forms for lead capture. Two iframes and a single video round out the rich media.

**How it's designed** — Dark developer-product aesthetic: pure-black canvas with white 55px Inter Display headings, body in Inter, and monospace faces (Fragment Mono / JetBrains Mono / DM Mono) reserved for code and data readouts — the classic 'data API for engineers' look. Dense imagery (181 imgs, 102 svgs) carries product screenshots and the glowing globe motif. Hosted on Framer (framerusercontent.com), so styling is token-driven with Framer's GUID CSS variables.

**Palette** — Black background, white headings/body text, monospace code accents; classic-blue default link color where unstyled.
**Fonts** — Inter Display (headings) + Inter (body), with Fragment Mono / JetBrains Mono / DM Mono for code and data.
