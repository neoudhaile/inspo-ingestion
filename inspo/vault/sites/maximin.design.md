# Maximillian Piras, Design Portfolio
> Amplifying human capabilities with delightful & instinctual technology.  ·  [maximin.design](https://www.maximin.design/)

![maximin.design](../../../screenshots/maximindesign.png)

**What it is** — The design portfolio of Maximillian Piras (@MVXMXM) — per its meta, 'product design for tech startups (user experience & user interfaces) focused on AI, branding, animation, & illustration.' MVXMXM.com resolves to this site.

**What it shows** — A gradient hero — 'Design Portfolio by Maximillian Piras / Amplifying human capabilities with delightful & instinctual technology' — above a set of tilted, drop-shadowed project cards organised by category (animating, ABOUT, WORK, MY AI, teaching / speaking / writing). Cards mix illustration with embedded video demos (7 video elements). The h1 reads 'Maximillian AI'.

**How it works** — A static site (no framework global, and notably zero external script hosts — fully self-contained) with a vertical scroll (~1,640px). Project cards are tilted in perspective and arranged around a category switcher; an 'ABOUT' link and a 'VIEW SOURCE ON GITHUB' link are the main outbound paths.

**How it's designed** — A vivid purple-to-indigo gradient hero sits over a white body; project cards are white with soft drop shadows, rotated in 3D perspective so the deck feels physical. Type pairs Archivo (loaded at 900 for the heavy 40px display h1) with Playfair Display SC for serif accents and Homemade Apple for a handwritten script flourish. Playful, tactile, illustration-forward.

**Palette** — Purple/indigo gradient hero on white, with black text
**Fonts** — Archivo (display, 900) with Playfair Display SC serif and Homemade Apple script accents
