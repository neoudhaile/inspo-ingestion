# Daytona - Secure Infrastructure for Running AI-Generated Code
> Run AI Code on Daytona  ·  [daytona.io](https://www.daytona.io/)

![daytona.io](../../../screenshots/daytonaio.png)

**What it is** — Daytona is a developer-infrastructure product that gives AI agents secure, disposable sandboxes to execute the code they generate. The hero pitch is literally its own <h1>: "Run AI Code on Daytona", and the meta description sells the headline numbers — 90ms environment creation, stateful operations, and enterprise-grade security.

**What it shows** — A long (11.5k px) marketing landing page: a dark hero with the run-AI-code promise, then stacked sections of product capabilities, code/terminal mockups, logos and stats, leading toward sign-up CTAs. There's a single embedded iframe and heavy use of inline SVG (226) and product imagery (97 images) to illustrate the sandbox/infra story.

**How it works** — It's a Framer-built static marketing site (assets served from framerusercontent.com, framer events script present). No app framework like Next/Nuxt — the page is Framer's renderer. GTM and a zeroclick.ai script handle analytics/attribution.

**How it's designed** — A near-black developer aesthetic: page background is rgb(10,10,10) with white headings, accented by a terminal green (#2ecc71) reserved for code text and a blue (#0080ff / #59acff) for interactive accents — all read from the site's own design tokens. Type is set in Inter Variable for UI with Berkeley Mono and IBM Plex Mono for code, reinforcing the infra/terminal feel. Letter-spacing is tightened (-0.02em) for a dense, technical headline look.

**Palette** — Near-black canvas (#0a0a0a) + white text, terminal-green (#2ecc71) code accent, electric blue (#0080ff/#59acff) interactive accent.
**Fonts** — Inter Variable (UI) + Berkeley Mono & IBM Plex Mono (code).
