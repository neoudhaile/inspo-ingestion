# Aman Kishore
> Currently, exploring and building my curiosities.  ·  [amanml.com](https://amanml.com/)

![amanml.com](../../../screenshots/amanmlcom.png)

**What it is** — The personal homepage and writing collection of Aman Kishore — previously building Legal AI at Harvey, co-founder of Mirage (acquired by Harvey), ex-NVIDIA (autonomous-vehicle simulation) and ex-Apple robotics. He describes the site's writing as deliberately 'post-it note' style.

**What it shows** — A short bio paragraph linking out to Harvey, Mirage and NVIDIA, then a long single-column index of bite-size essays split across themes — a 'Life' set (Besharam, 996, Post Its, Long Walks, Question Your Beliefs) and a dense run of AI/startup takes (Apps not Artifacts, Cursor is the new Powerpoint, LLMs are Humans, Replace not Augment, Infra for AGI, Recursive Companies).

**How it works** — An ultra-light static HTML page — one image, no framework, a single same-origin stylesheet, with only Google Tag Manager added for analytics. Each essay is its own flat .html file (besharam.html, 996.html, cursor.html …), classic hand-authored static-site structure.

**How it's designed** — Bare-bones document styling: transparent/white canvas, black text set in Inter, a centered ~800px max-width column, and a single classic-web blue rgb(0,102,204) for links. No CSS variables, no webfont payload beyond the system Inter stack — the design is intentionally close to an unstyled, readable text document.

**Palette** — White background, black text, classic-web blue #0066cc links
**Fonts** — Inter (system/sans stack); no webfont loaded
