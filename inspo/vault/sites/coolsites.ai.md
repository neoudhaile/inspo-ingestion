# CoolSites — Website prompts
> Cause everyone deserves a good Fu*king Website  ·  [coolsites.ai](https://www.coolsites.ai/)

![coolsites.ai](../../../screenshots/coolsitesai.png)

**What it is** — A curated gallery of website design ideas where every entry ships with a copy-pasteable AI build prompt. The pitch is blunt and self-aware — the real <h1> reads “Cause everyone deserves a good Fu*king Website” — and a Clerk sign-in gates the full prompts.

**What it shows** — Under the section heading “Website ideas,” a grid of live site previews rendered as embedded iframes (7 on first load), so you scroll a wall of real, running pages rather than static thumbnails.

**How it works** — Browse the gallery freely; each card is a live iframe preview. Authentication is handled by Clerk (clerk.coolsites.ai) and unlocks copying the underlying build prompt — “Sign in to copy the full build prompts.” No SPA framework global was detected; the page is a Tailwind v4 build served straight from coolsites.ai.

**How it's designed** — A warm, almost analog palette — cream canvas (#efdec8) carrying bold cherry-red foreground type (#b30100) with peach accents (#e9c8b4) — paired with a playful display face. The 72px <h1> is set in DynaPuff (rounded, bouncy), body copy in Google Sans, and Geist Mono is loaded for monospace touches. Tailwind v4 design tokens drive the spacing/radius scale (--radius .625rem).

**Palette** — Warm cream #efdec8 background, bold cherry-red #b30100 foreground/headings, peach accent #e9c8b4
**Fonts** — DynaPuff (playful display <h1>) + Google Sans (body/UI) + Geist Mono (mono)
