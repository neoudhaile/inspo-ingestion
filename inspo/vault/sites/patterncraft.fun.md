# Pattern Craft - Modern Background Patterns & Gradients Snippets
> Create stunning websites with our curated collection of 100+ modern CSS background patterns and gradients.  ·  [patterncraft.fun](https://patterncraft.fun/)

![patterncraft.fun](../../../screenshots/patterncraftfun.png)

**What it is** — Pattern Craft, an open-source library of 100+ copy-paste CSS background patterns and gradients by Megh Bari (github.com/megh-bari/pattern-craft; featured in Vercel's OSS program). The hero reads 'Craft Beautiful / Patterns Backgrounds'. One of Devster's inspo-dump links.

**What it shows** — A hero pitch ('Professional-grade background patterns and gradients. Easily copy the code…') over a very long 'Pattern Library' — a tiled gallery of background swatches in both light and dark variants (dot grids, mesh gradients, ruled grids, glows) where each tile is a live CSS preview you can one-click copy as CSS/Tailwind. A 'Buy Me Coffee / PayPal / UPI' support block and a Carbon ad sit alongside.

**How it works** — A long single page (~20,878px) where each pattern is rendered as live SVG/CSS rather than an image — 1,518 inline <svg> tiles drive the gallery — with one-click copy and live preview. Built on the shadcn/ui token system with GeistSans, monetized via Carbon Ads (cdn.carbonads.com) and donations; no JS framework global is exposed (a static/Next build).

**How it's designed** — Clean light docs-style UI in a slate palette: white ground (--background #fff) with a near-black slate foreground (--foreground #020618) and a slate primary (--primary #0f172b), so the colourful pattern swatches themselves provide all the visual energy against a quiet chrome. Type is GeistSans throughout; a shadcn chart palette (#f05100, #009588, #fcbb00…) is defined in tokens.

**Palette** — White ground (--background #fff) with near-black slate text (--foreground #020618) and a slate primary (--primary #0f172b); the colour comes entirely from the gallery of pattern swatches.
**Fonts** — GeistSans (variable) is the single loaded webfont, used across the whole UI.
