# Spectrum by Photon — open-source framework to bring agents to iMessage, WhatsApp, Telegram, Slack & more
> Bring Agents to the Interfaces Millions Already Use.  ·  [photon.codes](https://photon.codes/)

![photon.codes](../../../screenshots/photoncodes.png)

**What it is** — The landing page for 'Spectrum by Photon' — in its own meta description, 'an open-source framework that connects your agents to iMessage, Telegram, WhatsApp, X, Discord, Instagram, and other interfaces people use every day.' It is the site Daniel Tian's 'world's 1st iMessage App API for agents' tweet links (metadata resolves the t.co to photon.codes); the tweet's video ends on the CTA 'Available today at tryphoton.ai'. The framework is open-source on GitHub (photon-hq/spectrum-ts, ~3.2k stars).

**What it shows** — A long (12,882px) developer-marketing page. The hero shows a rainbow 'spectrum' prism of stacked gradient cards under the headline 'Bring Agents to the Interfaces Millions Already Use.' with a row of channel icons (iMessage, WhatsApp, Discord, Slack, Telegram, Instagram). Below: dark 'Cross Channel' and 'iMessage' sections pairing code blocks with live chat / app-card mockups; a 'First-class for the agent era.' feature grid (Low latency + high reliability / Adaptive extent rendering / Scale from four to millions / Built-in observability and control); a dark-green 'We keep everything secure.' card ('Dedicated infrastructure. Locked down by design.', 'SOC 2 ready for serious teams.'); a 'Trusted by the world's best agent teams and developers' testimonial wall; a 'Built for teams at every scale' Ditto case study (140k+, 4M+); the manifesto lines 'Nobody's going to download an app or visit a website just to talk to your agent.' / 'The best interface for your agent already exists.'; an animated 'Deploy your [Coding / Companion / Customer Support / Trading] agents to the platforms people actually live on.'; and a closing 'Start building with Spectrum today.'

**How it works** — A Framer-published marketing site (framerusercontent.com assets, events.framer.com; no app-framework global) with a heavy growth/analytics stack — PostHog (us-assets.i.posthog.com), Google Tag Manager, a Facebook pixel (connect.facebook.net), Apollo.io (assets.apollo.io) and Google Ads / DoubleClick — plus a CloudFront-hosted script. It is image-and-vector-driven: 99 <img> and 135 inline <svg>, with 0 <canvas>/<video>/<iframe>, across the 12,882px scroll. Outbound links go to the open-source repo (github.com/photon-hq/spectrum-ts), a Discord community, LinkedIn (photon-framework), Instagram (photon_community) and X (@photonhq).

**How it's designed** — Clean, Apple-adjacent light design built around a rainbow-'spectrum' brand motif. From getComputedStyle the surface is a very light grey (body rgb(245,245,247) ≈ #f5f5f7) with black text (rgb(0,0,0)); rather than a single flat accent, the 'colour' is the prism of gradients in the hero, echoed by the gradient feature tiles, while the code / demo panels invert to near-black for contrast. Display type is the light, wide 'PolySans Arabic VF Variable Slim' at weight 300 — the h1 'Bring Agents to the Interfaces Millions Already Use.' is 48px/300; body & UI use 'Aspekta' (400 and 550 loaded), code / labels use 'Azeret Mono', and a custom 'Photon_Symbol' icon font plus Inter are also loaded. Instrument Serif, Petrona, Geist Mono, Fragment Mono and IBM Plex Mono are declared but report 'unloaded'. No :root custom properties are exposed (Framer inlines styles), so the colour tokens above are the rendered values.

**Palette** — Very light grey canvas (#f5f5f7) with black text; the 'accent' is a rainbow-spectrum prism of gradients (hero + feature tiles), with near-black inverted panels for the code / chat demos.
**Fonts** — PolySans Arabic VF Variable Slim (Light 300) for display, Aspekta (400 / 550) for body & UI, Azeret Mono for code / labels, plus a custom Photon_Symbol icon font and Inter; Instrument Serif, Petrona, Geist Mono, Fragment Mono and IBM Plex Mono declared but unloaded.
