**What it shows** — An editorial deep-dive structured by section headings — how Claude Code navigates large codebases, why the harness matters as much as the model, and three configuration patterns from successful deployments — illustrated with 11 images, a video, and heavy inline SVG iconography (155 svg nodes).

**How it works** — A Webflow-built marketing/blog page (assets from cdn.prod.website-files.com, webflow-icons font). It's a standard scroll-through article (~15k px tall) closing with related posts and a “Transform how your organization operates with Claude” CTA. Analytics run through Google Tag Manager, Amplitude, and a Meta pixel.

**How it's designed** — Anthropic's house brand system: an oat/cream canvas (#faf9f5) with near-black ink text (#141413) and the signature clay/coral accent (#d97757). Headings are set in Anthropic Serif (52px h1), body in Anthropic Sans, and code in Anthropic Mono. The type scale is fully fluid via clamp() and laid out on a 12-column grid with a defined swatch palette (clay, fig, peach, cactus, plum, sky, etc.).
