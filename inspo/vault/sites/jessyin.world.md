# Jess Yin — hey there
>   ·  [jessyin.world](https://jessyin.world)

![jessyin.world](../../../screenshots/jessyinworld.png)

**What it is** — The personal site of Jess Yin (ex-finance, apparel founder, now building creative web experiences), explicitly styled as a macOS Finder window. It's an about/portfolio hub that frames her life and work inside a familiar desktop-file metaphor.

**What it shows** — A warm cream canvas with a left sidebar of 'files' (About, Writing, Projects, Say Hi) — the active one highlighted in soft pink — and a reading pane to the right. The About pane is a friendly first-person bio with key phrases (reading, writing, podcasts, SERENA LI, Inseam) highlighted like selected text, closing with X / Substack / TikTok links.

**How it works** — Navigation mimics a Finder window: click an item in the left sidebar to swap the content pane, rather than loading new pages or scrolling a long document. The viewport is fixed (no page scroll); a single <canvas> adds a subtle ambient touch. Inline highlighted keywords double as links into projects and contact.

**How it's designed** — Soft, tactile, personal: a warm cream ground (#f5f0e8) with rose-pink highlights (#fce4ec / #e8b4bc) and dark grey text, set in the system font for an honest, OS-native feel. The Finder metaphor is the whole concept — sidebar + pane, selection highlights, desktop calm — making a simple bio feel like poking around someone's computer.

**Palette** — Warm cream ground (#f5f0e8), rose-pink highlights (#fce4ec / #e8b4bc), dark grey text (#333), muted grey secondary (#888).
**Fonts** — system UI (-apple-system / system-ui)
