# 21st.dev - Crafted React components and templates, not AI slop | 21st
> A community registry of hand-crafted React components and templates. Start from real, polished UI instead of the bland AI average, and ship products that look like you, not everyone else.  ·  [21st.dev](https://21st.dev/)

![21st.dev](../../../screenshots/21stdev.png)

**What it is** — The gallery the tweet links to. Its h1 is 'Build something beautiful' and its meta description reads 'A community registry of hand-crafted React components and templates. Start from real, polished UI instead of the bland AI average, and ship products that look like you, not everyone else.' — a marketplace/registry of React UI you can preview, then copy as a prompt for an AI coding agent to recreate.

**What it shows** — A light hero with an Averia-Serif-Libre display headline over a very media-dense wall of live component and section previews — 122 <img>, 59 <video> and 274 inline <svg> — arranged in horizontal 'View all' carousels of bento cards, notification stacks, dashboards and marketing sections, each previewable and copyable as a prompt.

**How it works** — A React application served from 21st.dev; no meta-framework global (__NEXT_DATA__/__NUXT__ etc.) was exposed to the probe, but auth runs through Clerk (clerk.21st.dev), affiliate tracking through Tolt (cdn.tolt.io), plus Google Tag Manager, a Twitter/X Ads pixel and jsDelivr. The homepage renders inside a fixed 900px app shell with an internal scroll region.

**How it's designed** — A bright, editorial light theme. getComputedStyle reports a white body background oklch(1 0 0) with near-black body text oklch(0.141 0.004 285.824); the h1 renders at 60px in 'Averia Serif Libre' (loaded 400, normal + italic) — a quirky display serif that sets the 'crafted, not slop' tone — while body/UI type is 'General Sans' (loaded 500) with a mono stack for code. The only exposed :root colour token is the blue selection accent --color-selected #008fe9; General Sans and the mono stack are declared as --font-sans / --font-mono.

**Palette** — White canvas with near-black text (oklch 0.141) and a single blue selection/accent (--color-selected #008fe9); all the colour comes from the component previews themselves.
**Fonts** — General Sans (loaded 500) for UI/body and Averia Serif Libre (loaded 400, roman + italic) as the display serif for the h1; a mono stack (--font-mono) for code snippets.
