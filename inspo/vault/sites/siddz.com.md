# Siddharth Meena | Full-Stack Developer
> Full-Stack Developer & Software Engineer based in India — React, Next.js, TypeScript, Node.js.  ·  [siddz.com](https://siddz.com/)

![siddz.com](../../../screenshots/siddzcom.png)

**What it is** — The personal portfolio of Siddharth Meena (@buildwithsid), a full-stack developer based in India (h1: 'Siddharth Meena'). The tweet introduces it as his updated site and 'my cleanest design yet.'

**What it shows** — A single-page scroll broken into Tech Stack, Featured Projects (Onavix, Wittyr), Experience and a 'Let's Work Together' CTA, plus a Spotify 'now playing' track widget and links to X, GitHub and a cal.com booking page.

**How it works** — A long single-page scroll (~3,002px) with anchored sections; outbound links go to the live projects (onavix.com, wittyr.com), a Spotify track, GitHub (SiddDevZ) and a cal.com 30-minute call. Assets (Geist + JetBrains Mono) are self-hosted and no analytics host is loaded; the Geist family hints at a Next.js build although no framework global is exposed.

**How it's designed** — Light, monospace-forward developer aesthetic: a white ground (rgb(255,255,255)) with near-black text (rgb(17,17,17)), JetBrains Mono as the body face and Geist Sans for headings (h1 rgb(13,13,13)) — even Geist's pixel display variants are loaded. Buttons are ghost/transparent. There are no :root custom properties, consistent with a Tailwind/utility build.

**Palette** — White ground (rgb(255,255,255)) with near-black text (rgb(17,17,17)); a restrained near-monochrome scheme where links carry the only accent.
**Fonts** — JetBrains Mono (body) + Geist Sans (headings), with Geist pixel-display variants; all self-hosted (Inter is present but unused).
