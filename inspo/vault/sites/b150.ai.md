# B150 — The professional social network for Gen AI builders and creators
> Don't wait for the future. Build it.  ·  [b150.ai](https://b150.ai/)

![b150.ai](../../../screenshots/b150ai.png)

**What it is** — A Webflow-built marketing site for B150, pitched as “the professional network reimagined for Gen AI builders; where creators connect, learn, and launch real products together” — a LinkedIn-style network for AI makers. The real <h1> is the rallying cry “Don't wait for the future. Build it.” Note the bookmarked tweet (Apr 2026) sold b150.ai as a free Wispr Flow clone; the domain has since pivoted to this social network.

**What it shows** — A tall (~9.8k px) landing page that opens on a dark hero, then runs a wall of product/community imagery (145 <img>) interleaved with embedded demo clips (5 <video> plus a YouTube iframe), sections teasing Events, Jobs and a Marketplace, and a “Start building the future” CTA — closing on a giant “B150” wordmark footer.

**How it works** — A static Webflow build (assets from cdn.prod.website-files.com, based on the byq-studio template); no SPA framework global was detected. The functioning product is gated behind app.b150.ai (“Join Beta” / “Login”), so the marketing site is purely a funnel to the beta signup. Analytics and pixels run through Google Tag Manager, Amplitude, the Meta pixel, and a Twitter ads pixel; jQuery and YouTube load from CDNs.

**How it's designed** — A warm off-white canvas (#f2efe9) with near-black ink (#1f1915), punched up by a bright lime/chartreuse accent (#d4fd80) and coral/red highlights (#fa4149 / #fa725a). Big, very tightly-tracked Geist display type carries the hierarchy — a 120px <h1> with -8px letter-spacing — paired with Fragment Mono for labels and secondary text. A full Webflow design-token system defines the type scale, spacing, radii, and even a separate dark-mode “apps” palette for the product UI.

**Palette** — Warm off-white #f2efe9 canvas, near-black #1f1915 ink, lime/chartreuse accent #d4fd80, coral/red highlights #fa4149/#fa725a
**Fonts** — Geist (display + body, very tight tracking) + Fragment Mono (labels/secondary); LT Superior defined in tokens but not loaded
